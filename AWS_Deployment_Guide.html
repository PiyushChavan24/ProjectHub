Single-server approach: The React frontend is built into static files and served directly by Express. One EC2 instance handles everything — no separate hosting needed.

Step 1 — MongoDB Atlas (Database)

1
Go to mongodb.com/atlas and create a free account.
Create a new M0 (free) cluster in any region.
2
Under Network Access, add IP 0.0.0.0/0 (allow from anywhere).
Or whitelist only your EC2 instance's IP once it's launched.
3
Under Database Access, create a user with a password.
Copy the connection string — it looks like: 
mongodb+srv://<user>:<password>@cluster0.xxxxx.mongodb.net/projecthub?retryWrites=true&w=majority

Step 2 — Build the React Frontend

Run this on your local machine before uploading to the server:

cd frontend
npm install
npm run build       # produces frontend/dist/

Step 3 — Serve Frontend from Express

Add these lines to your backend server.js / app.js after all API routes:

const path = require('path');

// Serve the built React app
app.use(express.static(path.join(__dirname, '../frontend/dist')));

// All non-API routes return the React app (client-side routing)
app.get('*', (req, res) => {
  res.sendFile(path.join(__dirname, '../frontend/dist/index.html'));
});

Step 4 — Launch an EC2 Instance

1
Open AWS Console → EC2 → Launch Instance
2
Choose Ubuntu Server 24.04 LTS
Instance type: t2.micro (free tier eligible)
3
Create a new key pair (.pem file) — download and save it safely.
4
Configure Security Group — open these inbound ports:
PortProtocolPurpose
22TCPSSH access
80TCPHTTP (web traffic)
443TCPHTTPS (SSL)
3000TCPNode.js direct (testing)
5
Click Launch Instance. Note the Public IPv4 address.

Step 5 — Connect and Install Node.js

# Connect via SSH (from your local machine)
ssh -i your-key.pem ubuntu@<EC2-PUBLIC-IP>

# Install Node.js 20
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt-get install -y nodejs

# Verify
node -v    # should print v20.x.x
npm -v

# Install PM2 (keeps Node running after SSH disconnect)
sudo npm install -g pm2

Step 6 — Upload Your Code

Option A — SCP (copy from local machine):

scp -i your-key.pem -r "e:/Review 2" ubuntu@<EC2-PUBLIC-IP>:~/app

Option B — Git (recommended):

# On EC2:
sudo apt-get install -y git
git clone https://github.com/your-username/your-repo.git ~/app

Step 7 — Configure Environment & Install Dependencies

cd ~/app/backend
npm install

# Create the .env file
nano .env

Paste the following into the editor (replace values with your own):

PORT=3000
MONGO_URI=mongodb+srv://<user>:<password>@cluster0.xxxxx.mongodb.net/projecthub
JWT_SECRET=your_long_random_secret_here
HF_TOKEN=hf_your_huggingface_token

Save with Ctrl+O, then Ctrl+X to exit nano.

Step 8 — Start the Application with PM2

# Start the server
pm2 start server.js --name projecthub

# Save PM2 config so it restarts after a server reboot
pm2 save

# Generate the startup script (copy and run the printed command)
pm2 startup

# Check status
pm2 status
pm2 logs projecthub    # view live logs

Your app is now live at: http://<EC2-PUBLIC-IP>:3000

Step 9 — Route Port 80 to Node (No :3000 in URL)

# Redirect port 80 → 3000
sudo iptables -t nat -A PREROUTING -p tcp --dport 80 -j REDIRECT --to-port 3000

# Make the rule persist across reboots
sudo apt-get install -y iptables-persistent
sudo netfilter-persistent save

App is now at: http://<EC2-PUBLIC-IP>

Step 10 — (Optional) Custom Domain + HTTPS

1
Buy a domain (Route 53, Namecheap, GoDaddy, etc.) and set its A record to your EC2 Public IP.
2
Install Nginx + Certbot for free HTTPS: 
sudo apt install -y nginx certbot python3-certbot-nginx

# Get a free SSL certificate
sudo certbot --nginx -d yourdomain.com
3
Certbot auto-configures Nginx. Your app will be available at https://yourdomain.com
